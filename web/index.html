接上一张桌子

看板只读取投影，不发任何消息。token 只存在这个浏览器里。

第一次用？最简单的方式
在跑桌子的那台机器上执行 convene ui --seat seats/alice.seat.json， 它会打印一条链接。点开就直接进来，不用填任何东西。

已经有一条链接：直接打开即可。
手上有 alice.seat.json：把整个文件内容粘到上面，会自动识出 token、表和席位。
只想知道自己是谁：cat ~/convene-data/seats/alice.seat.json，复制里面的 token。

还没有席位？在宿主上依次执行：
convene keygen alice --out alice.owner.json
convene create table.json（打印 admin token）
convene join main --owner alice.owner.json --seat alice --out alice.seat.json
